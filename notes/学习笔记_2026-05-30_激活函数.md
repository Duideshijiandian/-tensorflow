# 学习笔记 2026-05-30：激活函数——为什么需要非线性

## 一句话总结

激活函数让模型"弯"过来，折点越多，越能逼近真实曲线。

---

## 核心问题：为什么不能全是 Dense？

### 推导

Day 2 的模型长这样：

```
Dense(3, input_shape=(3,))
```

数学上等价于 `y = W * x + b`，一个**线性变换**。

现在假如叠两层 Dense（不加激活函数）：

```
Dense(4) → Dense(3)
```

数学上：
- 第一层：`h = W1 * x + b1`
- 第二层：`y = W2 * h + b2`
- 代入：`y = W2 * (W1 * x + b1) + b2 = (W2*W1) * x + (W2*b1 + b2)`

> ❓ 自己推一下——这等价于几层 Dense？

答案：**一层**。因为 `W2*W1` 还是一个大矩阵，`W2*b1+b2` 还是一个偏置向量。多层线性变换叠在一起，还是线性变换。叠再多层也没用。

### 类比

想象你只能用直尺画线。给你 100 把直尺，你画出来的**还是直线**，不会变成曲线。

激活函数的本质：**在每个 Dense 之后掰一下**，让结果不再是输入的线性函数。

---

## ReLU 函数

```
ReLU(x) = max(0, x)
```

- x > 0 → 原样输出
- x ≤ 0 → 输出 0（关掉）

### 为什么 ReLU 能产生非线性？

ReLU 在 x=0 处有一个**折点**。一个折点 = 一次"掰弯"。

多个神经元 + ReLU → 多个折点 → 组合起来可以逼近任意曲线。

### 代码改动

```python
# Day 2: 纯线性
model = tf.keras.Sequential([
    tf.keras.layers.Dense(3, input_shape=(3,))
])

# Day 3: 加入 ReLU 打破线性
model = tf.keras.Sequential([
    tf.keras.layers.Dense(4, input_shape=(3,)),  # 扩展到 4 个神经元
    tf.keras.layers.ReLU(),                       # ← 折点在这里
    tf.keras.layers.Dense(3)                      # 输出层
])
```

变化：
1. 第一个 Dense 从 3 扩展到 4（更多神经元 = 更多折点）
2. 中间插入 `ReLU()` 层
3. epochs 从 1000 降到 100（有了非线性，拟合更快）

---

## 关键理解

| 没有激活函数 | 有激活函数 |
|---|---|
| 多层 Dense = 一层 Dense | 每层真正在做不同的事 |
| 只能画直线 | 可以画折线，逼近曲线 |
| 无论多少层，线性不可分的问题永远解不了 | 可以解决非线性分类问题 |
