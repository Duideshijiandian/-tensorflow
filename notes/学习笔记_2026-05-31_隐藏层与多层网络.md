# 学习笔记 2026-05-31：隐藏层——多层网络长什么样

## 一句话总结

隐藏层的本质是**特征提取层次**——每层在前一层的抽象上构建更高一层的抽象。

---

## 什么是隐藏层？

隐藏层 = 输入和输出之间的层。叫"隐藏"是因为我们看不到它该输出什么——没有标签来直接约束它。它是**机器自己的中间语言**。

### 一层 v.s. 两层

```python
# Day 3: 一层隐藏层
model = Sequential([
    Dense(4, input_shape=(3,)),
    ReLU(),
    Dense(3)
])

# Day 4: 两层隐藏层
model = Sequential([
    Dense(4, input_shape=(3,)),   # 隐藏层1
    ReLU(),
    Dense(4),                     # 隐藏层2
    ReLU(),
    Dense(3)                      # 输出层
])
```

> ⚠️ Dense + ReLU 合在一起才算「一层」。少了 ReLU，多层 Dense 退化成一层（见 Day 3 推导）。

---

## 不同层在做什么

| 层 | 职责 | 类比 |
|---|---|---|
| 隐藏层 1 | 从原始数据提取基础特征（"A 高""B 高"…） | 厨师尝第一口说"咸"、第二口说"酸" |
| 隐藏层 2 | 组合第一层的特征形成更高级判断（"A 高且 B 低"…） | 大厨看纸条判断"这是糖醋排骨方向" |
| 输出层 | 把高级判断映射到具体类别 | 决定上什么菜 |

第二层的输入是**第一层的输出**，不是原始数据。所以：

> **层越深，抽象层次越高。**

---

## 为什么"深度"有用

类比：识别人脸

```
像素 → 边缘/颜色块 → 眼睛/鼻子/嘴 → 人脸轮廓 → "这是张三"
      层1            层2            层3          输出
```

- 层 1 只看像素 → 学到边缘、颜色斑块
- 层 2 看层 1 的输出 → 学到器官形状
- 层 3 看层 2 的输出 → 学到整张脸的结构

层 2 不需要直接从像素里找眼睛——它看的是层 1 已经画好的边缘图。这比直接处理像素容易得多。

---

## 实验结果

2 层隐藏层（4 神经元 + 4 神经元）vs 1 层（4 神经元）：

```
两层隐藏层: loss 0.0018, 准确率 100%
```

在小数据上两层表现很好。但注意——数据只有 30 个样本 3 个特征，两层可能已经过拟合了。

---

## 关键公式

完整的两层网络结构：

```
输入 x (3维)
  ↓ W₁·x + b₁ (线性变换: 3→4)
  ↓ ReLU (非线性)
  ↓ W₂·h₁ + b₂ (线性变换: 4→4)
  ↓ ReLU (非线性)
  ↓ W₃·h₂ + b₃ (线性变换: 4→3)
  = 输出 logits (3维)
```
