# Day 19: 模型保存/加载

**日期：** 2026-06-10

## 为什么需要保存模型

训了十几分钟的模型，下次要用不能重新训一遍。

> 类比：写了一篇 3000 字的文章，Word 关了。明天打开继续编辑——点保存就完事。

## 保存哪三样东西

| 存什么 | 为什么需要 |
|---|---|
| **模型架构**（几层、什么激活函数） | 不然怎么重建网络？ |
| **权重**（每层的数值） | 训了半天的成果 |
| **优化器状态**（动量、Adam 的 m/v） | 继续训练不会「重置脚步」 |

> 类比：打游戏存档 — 不只要存「你在哪」，还要存「血量」「装备」「Boss 打了没」

## 保存 vs 加载

### 保存

```python
model.save('model.keras')  # Keras 原生格式（推荐）
# model.save('model.h5')   # HDF5 格式（旧，legacy）
```

### 加载

```python
model = tf.keras.models.load_model('model.keras')
```

### 文件存在判断

Python 里判断文件是否存在：

```python
import os
if os.path.exists('model.keras'):
    # 存在 → 加载
else:
    # 不存在 → 训练
```

## 两种使用场景

| 场景 | 做法 |
|---|---|
| 继续训练 | 加载 → **不 compile**（保留优化器状态）→ 直接 fit |
| 部署推理 | 加载 → 跳过训练 → 直接 predict |

> ⚠️ `model.compile()` 会**重置优化器状态**。如果加载后还要继续训练，不要重新 compile。

## 实战代码逻辑

```python
if os.path.exists('model.keras'):
    model = tf.keras.models.load_model('model.keras')  # 跳过训练
else:
    model = tf.keras.Sequential([...])                  # 定义模型
    model.compile(...)
    model.fit(...)  # 第一阶段训练
    model.fit(...)  # 第二阶段微调
    model.save('model.keras')                           # 保存

# 统一 predict
model.predict(Dataset2)
```

## 格式：.h5 vs .keras

| | .h5 | .keras |
|---|---|---|
| 格式 | HDF5（旧） | Keras 原生（新） |
| 状态 | Legacy，不推荐 | 当前推荐 |
| API | 完全一样 | 完全一样 |

```python
model.save('model.keras')                               # ✅ 推荐
model.save('model.h5')                                  # ⚠️ Legacy
model = tf.keras.models.load_model('model.keras')       # 通用，两种格式都能读
```

## 验证结果

- 第一次跑：训练 10 epoch → 保存
- 第二次跑：直接加载 → 秒出预测结果 ✅
