# Day 8：卷积直觉——"滑动窗口"替代"每个像素一个权重"

**日期：** 2026-06-01

---

## 一、Dense 层的本质问题

Dense 层把一张 28×28 的图当成 **784 个独立的数**。

- 输入是一维向量 `[1 × 784]`
- 每个权重绑死在特定像素坐标上
- 物体平移 3 个像素 → 784 个数几乎全变了 → 模型当"没见过的东西"

**类比：** Dense 看图片就像把报纸剪成碎片再排列——失去了空间结构。

---

## 二、卷积的核心思想

**参数共享：同一个检测器，滑过整张图。**

| | Dense | Conv2D |
|---|---|---|
| 检测方式 | 每个位置分配独立权重 | 同一个核扫过所有位置 |
| "7在左上角" vs "7在右下角" | 完全不同的事 | 同一个核都能认 |
| 参数 | 784×128 = 100,480 | 3×3×1×32+32 = 320 |

---

## 三、三个核心概念

### 1. 卷积核（Kernel / Filter）
一个小的数字矩阵（如 3×3），用来检测某种模式。

### 2. 卷积操作（Convolution）
核在图像上滑动，每个位置做：对应位置相乘 → 求和。

### 3. 特征图（Feature Map）
核扫完整张图后的输出，每个值 = "这个模式在这个位置出现的强度"。

---

## 四、通道数（Channels）

- 灰度图：1 通道（只有明暗）
- 彩色图：3 通道（R、G、B 各一层）
- Conv2D 输出通道数 = 卷积核数量（32 个核 → 32 个通道）

---

## 五、输出大小计算

**公式：输出宽 = 输入宽 - 核宽 + 1**

- 28×28 输入，3×3 核 → 26×26
- 想要保持 28×28？在周围补零（padding）

---

## 六、池化（Pooling）

Conv2D 之后特征图 26×26×32 = 21,632 个数，Flatten 后 Dense(10) 参数爆炸（216,330 个）。

**解决办法：MaxPooling2D**

- 把图切成 2×2 的小块，每块只保留最大值
- 无参数、可学习 = 0
- 26×26 → 13×13（面积压到 1/4）
- Flatten 后只 5,408 个，Dense(10) 参数降到 54,090

---

## 七、参数量对比

**自己用 `model.summary()` 验证：**

| 层 | CNN | Dense 网络 |
|---|---|---|
| 第一层 | Conv2D(32,3): **320** | Dense(128): **100,480** |
| 中间 | MaxPool: 0 | Dropout: 0 |
| 输出前 | Flatten → Dense(10): 54,090 | Dense(10): 1,290 |
| **总计** | **≈54,000** | **≈102,000** |

**CNN 参数量只有 Dense 的一半，但准确率更高（98%+ vs 97%+），且 val_loss 更低。**

## 八、遇到的核心问题和解决

### 问题 1：tensorflow 文件夹名遮蔽 pip 包
- **现象：** `AttributeError: module 'tensorflow' has no attribute '__version__'`
- **原因：** 项目子文件夹也叫 `tensorflow`，Python 优先导入它而非 pip 包
- **解决：** 重命名为 `tf-learning`，将 git 仓库提升到项目根目录

### 问题 2：Conv2D 参数计算不理解
- **现象：** 知道 Dense 参数 = 输入×输出+偏置，但 Conv2D 看不懂
- **解决：** 推导公式 `核宽×核高×输入通道数×核数量 + 核数量`，例如 3×3×1×32+32 = 320

### 问题 3：Flatten 后参数爆炸
- **现象：** Conv2D → Flatten → Dense(10)，输出层参数高达 21 万
- **解决：** 在 Conv2D 和 Flatten 之间插入 MaxPooling2D，空间压缩到 1/4

### 问题 4：batch_size 和 input_dim 概念混淆
- **现象：** 说 "batch_size 为 784"
- **纠正：** input_dim = 784（一张图的特征数），batch_size = 32（一次并行处理的图片数）
- **矩阵理解：** `[32 × 784] × [784 × 128] = [32 × 128]`

### 问题 5：新设备环境配置
- Python 3.12.10 → 3.12.4
- Git 仓库结构重构，`.claude/` 提升到根目录
- 配置 Stop hook 实现自动 git commit + push

## 十、比赛相关——AI 支持的自主学习

**今日体现的 AI 引导学习模式：**

1. **费曼式问答链：** "Dense 层丢失了什么信息？" → 自己推出"平移 → 全新输入" → 引出参数共享
2. **动手前先理解：** 用具体数字走过一遍卷积核怎么检测竖线，再写代码
3. **故意留 bug 让学习者发现：** 展示的伪代码缺少 MaxPool，让学习者自己发现参数爆炸问题
4. **对比学习：** 同时跑 Dense 和 CNN，用 `model.summary()` 和实际准确率做量化对比

**可作为比赛案例的素材：**
- AI 不是直接给答案，而是用递进提问逼出深层理解
- 概念讲解（通道数、卷积机制）用类比和具体数字，而非抽象公式
- 学习者通过"试错→发现问题→自己找解决方案"建立真正理解
