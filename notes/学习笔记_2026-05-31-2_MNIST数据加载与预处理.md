# 学习笔记 2026-05-31-2：MNIST 数据加载与预处理

## 一句话总结

从玩具数据切到真实 MNIST 手写数字数据——784 维输入、60000 样本、10 分类。Flatten、归一化、合适的神经元数、合适的学习率缺一不可。

---

## 关键发现

### 1. 图片要先 Flatten

Dense 只接受**一维向量**。`(28, 28)` 不拍平的话，Dense 会把每行当成一个样本的独立维度：

```
不拍平: (60000, 28, 28) → Dense → (60000, 28, 10) ❌ 多了个维度！
拍平:   (60000, 28, 28) → Flatten → (60000, 784) → Dense → (60000, 10) ✅
```

### 2. 归一化

像素 0~255 → 除以 255.0 → 0~1。让梯度更新更稳定。

### 3. 神经元数不是玄学

| 隐藏层神经元 | 效果 |
|---|---|
| 4 → 4 | loss 卡 1.7，信息瓶颈 |
| 128 | loss 0.016，正常收敛 |

784 个输入 → 4 个隐藏神经元，像 784 人挤一扇门，信息全丢。

### 4. 层数不是越多越好（惊喜发现！）

**一层 128 > 两层 128×128**——两层 loss 反而降到 2 左右。

原因：梯度反向传播时路径太长，多层容易梯度消散。MNIST 这种相对简单的任务，模型复杂了反而学不动。这是 ResNet 被发明出来的初衷。

### 5. 学习率太重要了

| learning_rate | 效果 |
|---|---|
| 0.1（从玩具数据沿用的）| 准确率 ~40%，步子太大，来回震荡 |
| 0.001（Adam 默认）| 准确率 **97.73%** |

---

## 最终模型

```python
model = tf.keras.Sequential([
    tf.keras.layers.Flatten(input_shape=(28, 28)),  # 784 输入
    tf.keras.layers.Dense(128, activation='relu'),   # 隐藏层
    tf.keras.layers.Dense(10)                         # 10 分类输出
])
model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True)
)
```

10 epoch，测试集准确率 **97.73%**，loss 0.016。
