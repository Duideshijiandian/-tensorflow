# Day 1 笔记：一个完整训练流程到底在做什么

## 学习方式

全程不写代码，AI 以"费曼式导师"角色用提问、类比、故意带小错的方式引导我自己推导。每遇到卡点，先自己尝试回答，AI 肯定正确部分再追问不严谨处。

## 从零推导出的 6 步训练流程

### 1. 数据 → 特征表
- 所有样本放在**一张统一表**里，每行一个样本，每列一个特征
- 特征分两类：0/1 型（是/否）和连续数值型（如 RGB 的 255）
- 训练前需要**归一化**（如 RGB 除以 255），否则 255 量级的特征会在误差分配时"嗓门太大"

### 2. 权重 → 随机初始化的评分表
- 形状：(输入特征数 × 输出类别数)
- 训练前是随机小数，训练后变成有意义的"评分规则"
- TF 里由层的 `kernel_initializer` 自动完成

### 3. 预测 → 特征 × 权重 → 各类别得分
- 加权求和：每个特征的输入值 × 对应权重，全部加总 = 该类别的分数
- 多分类时每个类别各有一套权重，最高分胜出
- TF 里对应 `Dense` 层

### 4. 损失 → 算误差
- 预测分数和正确答案之间的差距
- TF 里对应 `loss` 函数（如 `SparseCategoricalCrossentropy`）

### 5. 学习 → 误差反向调整权重
- 核心规则：**每个权重的调整量 = 该特征输入值 × 误差 × 学习率**
- 输入值大的特征"嗓门大"，误差分摊多；输入为 0 的特征不参与调整
- 学习率太大→震荡（跳过最优点）；太小→收敛太慢
- TF 里由 `optimizer` 自动完成（如 `Adam`、`SGD`）

### 6. 循环 → 重复直到收敛
- TF 里对应 `model.fit()`

## 关键卡点记录

1. **"模型到底改了什么东西"** —— 最初说"改特征向量"，经过快递站类比后理解到是改**权重**（评分表里的分数），不是改输入特征
2. **"误差怎么分配给各权重"** —— 推导出输入值越大→贡献越大→责任越大→调整越多
3. **"一张表还是多张表"** —— 从"每种水果一张特征表"修正为"一张统一特征表 + 每个类别各一套权重"

## TF/Keras 术语连线

| 我的理解 | TF/Keras 术语 |
|---|---|
| 数据归一化 | `Normalization` / `Rescaling` |
| 随机填权重 | `kernel_initializer` |
| 特征 × 权重算分数 | `Dense` 层 |
| 算误差 | `loss` 函数 |
| 根据误差调权重 | `optimizer` |
| 循环训练 | `model.fit()` |

## Day 1 代码实践：第一个 TF 模型（认三种水果）

### 完整代码演进过程

**第一阶段：3 个样本 + 默认配置**

```python
import tensorflow as tf

# 数据（3 个固定样本）
label = [0, 1, 2]
Features = [(1, 0, 0), (1, 1, 0), (1, 0.47, 0)]

tenser1 = tf.convert_to_tensor(label)
tenser2 = tf.convert_to_tensor(Features)

# 模型
model = tf.keras.Sequential([
    tf.keras.layers.Dense(3, input_shape=(3,))
])
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy')
model.fit(tenser2, tenser1, epochs=100)
```

问题：loss 从 ~10 降到 ~5.8，下降极慢。

诊断原因：
1. 忘记 `from_logits=True` —— Dense 输出原始分数，但 loss 期望概率 → 数值计算混乱
2. 3 个样本对应 12 个参数 → 模型在"背诵"而不是"学习"
3. Adam 默认学习率 0.001 偏小

**修正 1：加上 from_logits**

```python
model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True)
)
```

loss 从 1.5 → 1.3，有改善但仍慢。

**修正 2：调大学习率到 0.1**

```python
model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=0.1),
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True)
)
```

loss 从 0.9 → 0.2，显著改善，但仍是"背诵"。

**修正 3：扩充数据到 30 个样本（每种水果 10 个随机变体）**

```python
import random

# 苹果：R高 G低 B低（红）
[(random.uniform(0.7, 1), random.uniform(0, 0.2), random.uniform(0, 0.2))
 for i in range(10)]

# 香蕉：R高 G高 B低（红+绿=黄）
[(random.uniform(0.7, 1), random.uniform(0.7, 1), random.uniform(0, 0.2))
 for i in range(10)]

# 橘子：R高 G中 B低（橙）
[(random.uniform(0.7, 1), random.uniform(0.3, 0.6), random.uniform(0, 0.2))
 for i in range(10)]
```

30 个样本训练 200 轮后 loss ≈ 0.36。

**修正 4：用全新样本做预测（model.predict）**

```python
print(model.predict([(0.78, 0.1, 0.02),   # 苹果
                      (0.91, 0.7, 0.02),   # 香蕉
                      (0.84, 0.3, 0.02)])) # 橘子
```

第一次报错：`ValueError: Unrecognized data type` —— predict() 和 fit() 一样不接受裸 list，必须用 tf.convert_to_tensor() 转换。

修正后三行预测全部正确——苹果分最高、香蕉分最高、橘子分最高。

### 代码实践中的新卡点

1. **RGB 颜色搞反**：橘子最初写成 `(R低, G高, B高)` = 青色，修正为 `(R高, G中, B低)` = 橙色
2. **Softmax vs from_logits**：理解到 Dense 输出原始分数（logits），需要显式告诉 loss 函数做换算
3. **训练集 = 测试集 = 作弊**：用 `model.evaluate()` 评训练数据没意义，正确做法是用全新的 `model.predict()` 样本
4. **fit()/predict() 不接受裸 list**：必须 `tf.convert_to_tensor()` 转张量
5. **香蕉 vs 橘子难区分**：两者 R 都高、B 都低，只靠 G 区分——说明需要更多特征（如形状、纹理）
