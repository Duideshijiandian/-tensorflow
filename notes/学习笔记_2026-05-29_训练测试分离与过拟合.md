# Day 2 笔记：训练/测试集分离与过拟合

## 核心概念

### 训练集 vs 测试集
- **训练集**：给 `model.fit()` 用的数据，模型要从这里学规律
- **测试集**：不给模型看答案的数据，只用来验证模型学没学到真正的规律
- Day 1 用训练数据测准确率 = 作弊（题目都背过了当然全对）

### 过拟合（Overfitting）
- 模型在训练集上越练 loss 越低，但测试效果不升反降
- 本质：模型在"背诵"而不是"学习"
- 实验数据：

| 训练轮数 | 训练 loss | 测试准确率 |
|---|---|---|
| 10 | 0.795 | 80% |
| 100 | 0.287 | 100% |
| 1000 | 0.053 | 100% |

- 从 100 轮到 1000 轮，loss 降了 6 倍但准确率没变——多出来的努力是"过度背诵"，没有收益
- 继续训下去测试准确率可能反而下降，那才是经典过拟合

### 训练 loss vs 测试准确率的对应关系
- loss 很低但准确率不高 → 过拟合（背太熟，换新题不会）
- loss 适中但准确率高 → 学到了真正的规律
- 两者一起看才能判断模型好坏

## 代码实践

### 最终代码结构
```python
# 1. 训练集（30 个样本，不碰）
# 2. 测试集（15 个新样本，独立生成）
# 3. model.predict() 输出存变量，避免重复调用
# 4. tf.argmax(结果, axis=1) 取每行最高分位置
# 5. 与测试 label 逐行对比算准确率
# 6. 分别跑 10/100/1000 轮对比
```

### 踩坑记录
1. **类型不匹配**：`tf.convert_to_tensor` 默认 int32，`tf.argmax` 默认 int64，比较时类型必须一致（加 `dtype=tf.int64` 或 `output_type=tf.int32`）
2. **predict 重复调用**：错误地在循环里反复调 `predict()`，应该把结果存到变量里复用
3. **argmax axis 搞混**：axis=0 沿行找（列内最大），axis=1 沿列找（行内最大）；取每个样本的预测类别用 axis=1
4. **`jieguo[i]` 降维**：`jieguo` 是 (15, 3)，`jieguo[i]` 变 (3,)，只剩 axis=0
