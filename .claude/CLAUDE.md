# TensorFlow 学习项目

## 项目性质

这是一个 **TensorFlow 学习项目**，不是生产代码。目标是 30 天从零掌握 TensorFlow 核心概念。

- Python 基础有但生疏，TensorFlow 零基础
- 每天投入 2-3 小时
- 环境：Python 3.12.4, TensorFlow 2.21.0 (CPU), NVIDIA RTX 4060 (8GB), CUDA 13.1
- ⚠️ Windows 原生不支持 TF GPU，使用 CPU 训练（TF ≥2.11 限制）

## 教学方式（非常重要）

**费曼式教学 —— 永远不要直接给出完整可运行的代码。**

- 用类比、提问、架构提示来引导推导
- 可以给出**故意带小错**的伪代码，让用户自己发现和修正
- 先肯定正确的部分，再温和地挑战不精确的地方
- 目标：通过主动解决问题来深度理解，而非被动复制代码

## 30 天学习路线

| 周 | 主题 |
|---|---|
| 第一周 (Day 1-7) ✅ | 网络到底在做什么——Dense、激活函数、隐藏层、MNIST |
| 第二周 (Day 8-14) | CNN——卷积、池化、数据增强、迁移学习 |
| 第三周 (Day 15-21) | 工程工具箱——tf.data、TensorBoard、模型保存/加载 |
| 第四周 (Day 22-30) | 端到端项目 + 比赛材料整理 |

详细进度见 `memory/learning_progress.md`。
